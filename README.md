# ProcessManager
> Современный диспетчер процессов с управлением приоритетами, CPU Affinity и иерархией.

---

## Описание
**ProcessManager** - это кроссплатформенный инструмент для мониторинга и управления процессами операционной системы.  
Приложение позволяет в реальном времени наблюдать за запущенными процессами, менять их приоритеты, привязывать к конкретным ядрам процессора, просматривать потоки, строить дерево иерархии и визуализировать загрузку системы.

---

## Функциональность

**Просмотр процессов**

Отображение полного списка запущенных процессов с информацией: имя, PID, приоритет, объём используемой памяти (МБ), количество потоков, процессорное время и наличие графического окна.
Режим дерева процессов — иерархическое отображение процессов в формате «родитель → дочерние», построенное на основе данных WMI (Win32_Process).
Автоматическое обновление списка с настраиваемым интервалом (по умолчанию — каждые 5 секунд).
Принудительное обновление вручную по клавише F5.

**Управление процессами**

Завершение процесса — принудительное завершение выбранного процесса (через контекстное меню или клавишу Delete).
Изменение приоритета — установка одного из трёх уровней: Normal (обычный), High (высокий), RealTime (реального времени). При выборе RealTime выводится предупреждение о возможной дестабилизации системы.
Настройка CPU Affinity — выбор конкретных ядер процессора, на которых будет выполняться процесс. Маска отображается в шестнадцатеричном и двоичном форматах.

**Фильтрация и поиск**

Поиск процессов по имени в режиме реального времени.
Фильтр «Только GUI» — показывает только процессы, имеющие графическое окно.
Фильтр «Только системные» — показывает только фоновые/системные процессы (без окна).

**Мониторинг и визуализация**

**Линейный график загрузки CPU** — отображает динамику общей загрузки процессора в реальном времени (обновляется каждую секунду, хранит последние 30 измерений).
**Круговая диаграмма памяти** — показывает топ-10 процессов по потреблению оперативной памяти.

## Требования
ОС: Windows 7 и выше
.NET Framework 4.7.2+ (или соответствующая версия .NET)
Рекомендуется запуск от имени администратора для полного доступа к системным процессам

## Запуск

Клонируйте репозиторий или скачайте исходный код.
Откройте решение в Visual Studio.
Восстановите NuGet-пакеты (LiveCharts.Wpf).
Соберите проект (Ctrl+Shift+B) и запустите (F5).

**Поддерживаемые ОС**:Windows 10/11
